# License Rationale

I chose the CC BY-SA 4.0 license for my portfolio because it embodies the open-source values that fueled my success as a system and software engineer, where tools like Linux and the GNU Project were essential to my growth. Now, as a learning designer crafting training content for first responders, I’m committed to sharing my work freely so others can use, adapt, and enhance it to meet diverse needs. The CC BY-SA 4.0 license ensures I’m credited for my contributions while requiring derivative works to stay open, promoting collaboration in first responder education, just as open-source software shaped my own early learning and career.
